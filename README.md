# Substack Inbox

Chrome / Brave extension that:

1. Sends `https://substack.com/` (and `/home`) to `/inbox`
2. Hides the **Home** item in the left sidebar (leaves the Substack logo)
3. Hides **Related notes** under a note when you open comments
4. After you publish a note, stays off Home (sends you to Inbox instead of the Home feed)

Does not touch publication sites (`yourname.substack.com`).

## Install in Brave (or Chrome)

1. Open `brave://extensions` (Chrome: `chrome://extensions`)
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select this folder: `~/substack-inbox`
5. Visit [substack.com](https://substack.com/) — you should land on Inbox, with no Home row in the sidebar
